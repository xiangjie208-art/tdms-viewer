# 一键制作机器学习数据集：设计规范

**日期：** 2026-09-20  
**状态：** 已于 2026-09-20 确认
**目标版本：** `v2.12.0`  
**范围：** 将多个分子文件夹中已经人工保存的信号片段汇总为一个可直接供后续机器学习代码读取的完整数据集。

## 1. 背景与目标

实验数据按分子类别分别保存在文件夹中。用户会逐个打开这些文件夹，通过自动寻簇或手动框选判断并保存有效片段。数据集制作阶段需要选择这些分子文件夹的上一级总目录，由软件读取各文件夹的默认自动会话，把已保存片段统一重新载入、换算、计算特征并导出。

本功能只负责制作完整数据集，不划分训练集、验证集和测试集。不同实验批次中属于同一种分子的片段可以通过编辑标签合并为同一类别。导出的原始片段和特征表保持一一对应，供后续机器学习程序决定划分和建模方式。

## 2. 使用流程

1. 用户在“筛选记录”页面点击“制作机器学习数据集…”。
2. 用户选择一个总目录。软件只扫描其一级子文件夹；每个一级子文件夹代表一个待映射的分子类别。
3. 软件读取每个子文件夹对应的默认自动会话，并统计该文件夹中的 TDMS 文件数和已保存片段数。
4. 对话框显示类别预览表。用户可以决定是否使用某个文件夹，并编辑其数据集标签；标签默认等于文件夹名。
5. 用户设置全数据集统一的“特征峰幅值阈值（pA）”，默认值为 `10 pA`，并选择导出位置。
6. 用户点击“制作数据集”。后台任务依次处理所选文件夹和片段，界面持续显示进度，并允许用户停止。
7. 成功后，软件打开完成摘要，显示有效样本数、跳过样本数、输出目录及每条跳过记录的来源和原因。

没有默认会话或没有已保存片段的子文件夹显示 `0`，默认取消勾选。标签为空、没有勾选任何含有效片段的来源或没有选择导出位置时，“制作数据集”按钮不可用，并在界面中说明原因。

## 3. 界面设计

### 3.1 主窗口入口

在“筛选记录”页现有导出按钮附近增加独立按钮：

```text
制作机器学习数据集…
```

该入口不依赖当前已打开的数据文件夹。用户可以在任何时刻打开对话框并选择总目录。

### 3.2 数据集对话框

对话框包含：

- 总目录选择栏；
- 类别预览表，列为“使用”“分子文件夹”“数据集标签”“TDMS 数量”“已保存片段数量”；
- “特征峰幅值阈值（pA）”数值框，默认 `10`；
- 导出位置选择栏；
- 进度条和当前处理内容；
- “制作数据集”“停止”“关闭”按钮。

只有“数据集标签”可直接编辑。多个文件夹允许填写同一标签，从而合并为同一类别。阈值数值框使用项目现有的滚轮安全控件，页面滚动时不会误改数值。

任务运行期间锁定目录、表格、阈值和制作按钮，启用停止按钮。停止是协作式取消：当前一次读取或写入完成后终止后续处理，清理临时目录，不留下不完整的最终数据集。

## 4. 输出格式

每次导出都在用户选择的位置创建新的时间命名目录：

```text
TDMS机器学习数据集_YYYYMMDD_HHMMSS/
├─ dataset.csv
└─ waveforms/
   ├─ sample_000001.npz
   ├─ sample_000002.npz
   └─ ...
```

如果同一秒内目标名称已经存在，在名称末尾追加 `_2`、`_3` 等序号。导出先写入同级隐藏临时目录；所有有效样本和 `dataset.csv` 完成后，再把临时目录重命名为最终目录。有效样本数为零、用户停止或发生无法继续的整体错误时，删除临时目录，不创建最终目录。

### 4.1 波形 NPZ

每个有效片段生成一个压缩 NPZ，仅包含两个一维 `float64` 数组：

- `time_s`：从 `0` 开始，步长为原通道采样间隔；
- `current_pa`：未滤波、统一换算为 pA 的原始采样值。

文件名使用稳定的顺序编号 `sample_000001.npz`。同一次导出按照“一级文件夹名称、TDMS 自然排序、通道、片段起始索引、片段结束索引”的顺序生成样本编号，使输入不变时行序和编号保持一致。

### 4.2 `dataset.csv`

CSV 使用 UTF-8 with BOM（`utf-8-sig`），每行对应一个实际存在的 NPZ 文件。列按以下顺序排列。

来源与追溯字段：

1. `sample_id`
2. `label`
3. `source_folder`
4. `source_file`
5. `channel`
6. `selection_method`
7. `start_index`
8. `end_index`
9. `start_s`
10. `end_s`
11. `sampling_rate_hz`
12. `native_unit`
13. `native_to_pa_factor`
14. `baseline_pa`
15. `peak_threshold_pa`
16. `waveform_file`
17. `app_version`
18. `feature_version`

波形统计字段：

19. `duration_ms`
20. `sample_count`
21. `mean_amplitude_pa`
22. `median_amplitude_pa`
23. `std_amplitude_pa`
24. `rms_amplitude_pa`
25. `max_amplitude_pa`
26. `amplitude_iqr_pa`
27. `positive_area_pa_ms`
28. `signal_energy_pa2_ms`

峰特征字段：

29. `peak_count`
30. `peak_rate_hz`
31. `peak_amplitude_mean_pa`
32. `peak_amplitude_std_pa`
33. `peak_amplitude_max_pa`
34. `peak_width_mean_ms`
35. `peak_width_std_ms`
36. `interpeak_interval_mean_ms`
37. `interpeak_interval_std_ms`

频谱特征字段：

38. `dominant_frequency_hz`
39. `spectral_centroid_hz`
40. `spectral_bandwidth_hz`
41. `spectral_entropy`
42. `bandpower_0_100`
43. `bandpower_100_250`
44. `bandpower_250_500`
45. `bandpower_500_1000`

`source_folder` 是相对于所选总目录的一级文件夹名，`source_file` 是相对于分子文件夹的 TDMS 文件名，`waveform_file` 使用相对于数据集目录的 POSIX 风格路径，例如 `waveforms/sample_000001.npz`。

`start_index` 是片段第一个样本在原始通道中的索引；`end_index` 采用 Python 切片语义，是片段最后一个样本之后的位置。`start_s = start_index × dt`，`end_s = (end_index - 1) × dt`。这样 `current_pa` 精确对应原始数组的 `[start_index:end_index]`。

`selection_method` 根据会话记录推断：包含 `cluster_detection` 的片段写 `cluster_review`，其余片段写 `manual`。该字段只用于追溯，不作为默认模型输入。

## 5. 单位与基线

单位换算集中到独立模块，供自动寻簇和数据集制作共用：

- `A → pA`：`1e12`
- `mA → pA`：`1e9`
- `uA`、`µA`、`μA → pA`：`1e6`
- `nA → pA`：`1e3`
- `pA → pA`：`1`
- `V`、`volt`、`volts → pA`：`1000`，沿用当前仪器标定

单位字符串先去除首尾空白；电压单位不区分大小写。无法识别的单位不会猜测换算关系，对应片段会被跳过并记录原因。

同一个“TDMS 文件＋通道”只加载一次。完整通道换算为 pA 后，取其全部有限采样值的中位数作为 `baseline_pa`。片段的全部统计和峰检测都基于：

```text
amplitude_pa = current_pa - baseline_pa
```

NPZ 中仍保存未扣除基线的 `current_pa`，确保原始片段可以被重新处理。

## 6. 特征定义

### 6.1 基础约定

- `sample_count` 为片段样本数。
- `duration_ms = max(sample_count - 1, 0) × dt × 1000`。
- 均值、中位数、标准差、RMS、最大值和四分位距均基于 `amplitude_pa`。
- 标准差使用总体标准差（`ddof=0`）。
- `positive_area_pa_ms` 是 `max(amplitude_pa, 0)` 对时间的梯形积分，单位为 pA·ms。
- `signal_energy_pa2_ms` 是 `amplitude_pa²` 对时间的梯形积分，单位为 pA²·ms。

只有一个采样点时，两项积分和时长均为 `0`；其他可计算统计量仍按该点计算。原始波形或换算结果包含非有限值时，仅允许基线计算忽略完整通道中的非有限值；片段中出现任何非有限值则跳过该片段，避免向数据集写入无效数值。

### 6.2 峰特征

全数据集使用同一个 `peak_threshold_pa`。`amplitude_pa` 连续严格高于该阈值的样本组成一个峰区间：

- 峰高为该区间内 `amplitude_pa` 的最大值；
- 峰位置为最大值首次出现的采样索引；
- 峰宽为区间样本数乘以 `dt`；
- 峰间隔为相邻峰位置的时间差；
- `peak_rate_hz = peak_count / (sample_count × dt)`，空片段不进入导出。

人工保存的片段全部进入数据集，不再按峰数量进行二次过滤。没有峰时，所有峰统计量为 `0`；只有一个峰时，峰间隔均值和标准差为 `0`；只有一个峰宽或峰高时，相应标准差为 `0`。这些规则保证特征列保持纯数值。

### 6.3 频谱特征

频谱输入为去除片段自身均值后的 `amplitude_pa`，再乘 Hann 窗并进行实数 FFT。功率定义为复频谱模长的平方。特征只使用 `0 < f ≤ min(1000 Hz, Nyquist)` 的正频率点：

- 主频是功率最大的频率，功率并列时取较低频率；
- 频谱质心是按功率加权的频率均值；
- 频谱带宽是围绕质心的功率加权标准差；
- 频谱熵基于归一化功率分布，并除以 `log(N)` 归一到 `0–1`；
- 四个频带功率保存为该频带功率占 `0–1000 Hz` 可用正频率总功率的比例。

频带采用 `[0,100)`、`[100,250)`、`[250,500)`、`[500,1000] Hz`。直流分量不计入任何频带。采样率不足时只使用 Nyquist 以内实际存在的频率；常量信号、少于两个样本、没有可用正频率或总功率为零时，全部频谱特征填 `0`。

首版特征口径记为 `FEATURE_VERSION = "1"`。后续若改变特征定义或数值口径，必须提高该版本，不静默改变已有含义。

## 7. 来源发现、去重与异常处理

软件只扫描总目录下的一级子文件夹，并在每个子文件夹中使用现有 `discover_tdms` 规则发现该层的 `.tdms` 文件。会话由现有 `load_session(folder)` 读取。类别预览中的片段数量按会话 `regions` 条目计数，不提前读取大型波形。

数据集构建时对每条 region 解析原文件、通道和样本边界。完全相同的“分子文件夹＋文件＋通道＋起始索引＋结束索引”只保留第一次出现的一条。标签不会参与去重，因为同一来源片段不应在同一次数据集中重复出现。

以下问题只跳过受影响样本，其他有效样本继续导出：

- 原 TDMS 文件缺失；
- TDMS 无通道或读取失败；
- 会话中记录的原通道已不存在；
- 采样间隔不是有限正数；
- 起止索引缺失、反向、为空或越界；
- 原单位无法换算为 pA；
- 完整通道没有有限值，无法计算基线；
- 片段包含非有限采样值；
- 写入该样本时发生文件错误。

跳过记录保存在内存中，并在完成摘要中显示“文件夹 / 文件 / 通道 / 区间”和简明原因；不额外生成错误报告文件。只有成功写入 NPZ 的样本才会写入 `dataset.csv`。如果某个样本的 NPZ 写入后续步骤失败，立即删除该 NPZ，且不写 CSV 行。

目录不可创建、临时目录不可写、CSV 无法完成或最终目录无法重命名属于整体错误。软件清理临时输出并显示错误信息。

## 8. 代码结构

新增与调整的职责边界如下：

- `src/tdms_fingerprint_viewer/units.py`：保存 pA 换算常量和 `current_factor(unit)`；自动寻簇与数据集导出共同使用。
- `src/tdms_fingerprint_viewer/dataset_export.py`：不依赖 Qt 的来源发现、特征计算和数据集写出逻辑；公开 `FEATURE_VERSION`、`DATASET_COLUMNS`、`discover_dataset_sources(...)`、`extract_sample_features(...)` 和 `build_ml_dataset(...)`。
- `src/tdms_fingerprint_viewer/dataset_dialog.py`：对话框、类别表、后台任务、进度、停止和完成摘要。
- `src/tdms_fingerprint_viewer/cluster_panel.py`：改为从 `units.py` 导入换算逻辑，保持现有寻簇行为。
- `src/tdms_fingerprint_viewer/main_window.py`：增加入口并打开数据集对话框。
- `tests/test_dataset_export.py`：覆盖单位、特征、来源发现、去重、有效输出、局部失败、取消和原子完成。
- `tests/test_dataset_dialog.py`：覆盖默认值、类别编辑、按钮有效性、后台任务状态和摘要呈现。
- `README.md`、`README.en.md`、`docs/USER_GUIDE.md`、`CHANGELOG.md`：更新中英文功能说明、使用步骤和版本记录。

核心接口使用不可变的来源描述和值对象，避免 Qt 控件状态渗入纯逻辑层。`build_ml_dataset(...)` 接受进度回调和取消检查函数，因此命令式测试和后台界面可以复用同一实现。

## 9. 测试与验收

实现按测试驱动方式进行。验收至少覆盖：

1. A、mA、uA/µA/μA、nA、pA 和仪器 V 单位得到正确 pA 波形与基线，未知单位被明确跳过。
2. 合成波形的基础统计、连续阈值峰、峰宽、峰间隔和频谱特征符合本规范，零峰与单峰结果全部为有限数值。
3. 一级子文件夹能正确发现默认会话；无记录文件夹显示 0，多个文件夹可映射到同一标签。
4. 保存于会话中的相对路径和索引能精确还原 NPZ 波形，`time_s` 从零开始，CSV 行与 NPZ 一一对应。
5. 重复片段只输出一次；缺失文件、缺失通道、越界索引、非有限数据和未知单位只跳过相应样本。
6. 取消或整体失败不留下最终目录和临时目录；成功时只出现 `dataset.csv` 与 `waveforms/`。
7. 对话框使用默认 `10 pA`，滚轮不会误改阈值，运行期间控件状态和完成摘要正确。
8. 全部既有测试继续通过，Ruff 检查和 `git diff --check` 通过。

功能完成标准是：用户选择包含多个分子文件夹的总目录、确认标签并点击一次按钮后，可以得到结构最简、可追溯、所有数值特征有限且每行对应一个原始片段 NPZ 的完整数据集。
