# 用户指南

## 选择数据

“数据文件夹”应直接包含 `.tdms` 文件。程序默认选择长度最长的数据通道；若文件包含多个通道，可在“数据通道”下拉框切换。

## 局部窗口与时间

拖动右上总览中的选择框即可改变局部窗口。也可精确输入起点、终点或窗口宽度，并在秒与毫秒之间切换。窗口到达数据边界时会自动限制，且至少保留 16 个采样点用于频谱计算。

在左下局部波形图内按住鼠标右键左右拖动，可以连续查看当前区间前后的数据；滚轮缩放可以调整查看范围。总览选区、时间输入、统计量和局部频谱会同步更新。平移到文件起点或终点时会自动停止并保持窗口宽度；仅调整纵轴不会改变分析区间。若 FFT 范围选择“完整文件”，频谱仍分析整个文件。

局部波形右上角提供三种框选模式，默认选中时间框选。点击图标后直接用左键拖动，无需按住 Shift。框选完成后保持当前模式，可以连续框选；任何模式下均可按住右键拖动平移，松开后左键继续当前框选模式：

- 时间框选：选框高度固定为当前绘图区全高，左右边界随拖动变化；松开后只改变时间范围，纵轴显示范围不变。
- 纵轴框选：选框宽度固定为当前绘图区全宽，上下边界随拖动变化；松开后只改变纵轴显示范围，时间范围和 FFT 分析区间不变。
- 矩形框选：宽高均随拖动变化，松开后同时调整时间和纵轴显示范围。

三种选框在拖动时均有半透明预览，支持反向拖动。时间范围过窄时自动扩展到最小分析长度，范围始终限制在文件内。需要缩小查看更大范围时可使用鼠标滚轮。

## 窗口布局

拖动灰色分隔线可调整上下区域的高度，以及各行左右窗口的宽度。顶部“收起配置栏／展开配置栏”控制参数面板，“恢复默认布局”恢复初始四窗口排列。正常退出时记住分隔比例及配置栏显示状态。布局调整不改变数据分析范围。

## 自动寻簇操作

“文件夹一键寻簇”使用点击时的参数，对当前文件夹内所有 TDMS 的当前同名通道进行完整记录分析（不受当前框选时间限制）。自动基线逐文件估计，幅值按每个文件单位换算。后台依次处理，显示进度；文件下拉框标示候选簇数或失败状态。缺少同名通道、单位无法换算或数据异常的文件会记录失败并继续，失败详情可悬停进度说明查看。可点击“停止”，当前计算结束后停止，保留已完成候选。切换文件夹也会停止原任务。候选仅缓存在本次运行中，不自动保存为筛选记录，仍需人工确认保存。

顶部“上一文件／下一文件”及文件下拉框可直接切换当前文件夹内的 TDMS 文件，右侧显示文件序号。它与“数据与频谱”页的文件列表同步，不需要离开寻簇页。切换文件会优先恢复已有的批量候选；尚未分析的文件可点击“预览寻簇”。已保存片段保留。下方“上一簇／下一簇”用于浏览当前文件的候选簇。

在“自动寻簇”页设置高于基线的幅值、高斯窗宽（FWHM，毫秒）、分簇阈值，以及自动中位数或手动固定基线。可分析当前完整文件或当前框选区间。基线值和高于基线的幅值统一以 pA 输入，自动估计结果与检测线数值也以 pA 显示；计算时换算回通道原生电流单位，原始数据和导出数据的单位不变。本测量设置已确认 1 V = 1000 pA，V/Volt/Volts 通道按此标定参与寻簇，界面显示标定关系，保存记录包含换算系数；这不是通用电压换算，换用仪器或增益后需重新确认。其他未知单位仍不能直接以 pA 寻簇。初始 40 ms / 0.1 / 15 pA 仅供试调。适用于稳定基线、向上脉冲；存在漂移时请先检查基线，NaN/Inf 数据会拒绝处理。

点击“预览寻簇”后，总览和局部图显示候选阴影及幅值检测线。点击候选阴影或表格，可定位该簇并显示前后上下文；“上一个／下一个”逐簇浏览。前后上下文不会自动加入保存范围。使用现有框选工具可调整最终边界，点击“保存当前片段”才会加入筛选记录，随后使用已有导出功能。保存数据仍为原始采样值，附带本次寻簇参数；不新增特征提取或分类步骤。

重新调参会清空批量候选缓存，不删除已保存片段；切换文件可继续查看该文件的批量候选。已执行参数按原生单位记住，候选列表不跨重启恢复。边缘簇用 * 标记，终点为不包含的右边界，时长为采样点数乘采样间隔。单峰簇不自动删除。每段连续超幅值阈值的区间取一个最高点，以单位峰高、6σ 截断的高斯窗叠加后按阈值分段；这是明确的工程定义，并非论文作者代码的精确复现。

## 频谱设置

局部波形向外滚轮缩小时，纵轴扩大至当前可见数据最低值、最高值之外各留 20% 幅度跨度后停止扩大，横轴继续缩放。新进入可见范围的峰值会自动扩展纵轴；向内滚轮放大仍支持双轴缩放，纵轴框选后也可逐步缩小恢复。此限制只作用于波形区域内的向外滚轮操作，不影响右键平移或手动框选。

默认导出单图采用白底、黑色细线、四边边框、向内主次刻度和无网格样式，尺寸为 2148 × 894 像素。坐标轴使用英文标签及实际数据单位，保留当前查看范围；界面颜色、网格与线宽设置不影响这套导出样式。新保存的区间快照和组合图也采用白底样式。此前保存的区间仍使用原快照，如需新样式，请跳转到该区间后重新导出或保存。

配置栏的“显示主题”中可开启或关闭背景网格，并通过“线条粗细”输入框调整曲线线宽（0.2–5 pt，默认 0.75 pt）。设置立即作用于总览、局部波形、频谱及空白参考曲线，并在重启后保留；切换颜色主题也会保留这两项设置。

频谱默认显示 **0–1000 Hz**，频率和幅值均采用线性坐标。点击频谱右上角的“频率范围…”可输入起始、终止频率，或恢复 0–1000 Hz；确认后样品和空白参考立即更新。这里只调整显示范围，完整频谱计算结果及峰值分析不变。

频率范围会随会话保存。仍可手动启用频率或幅值对数坐标；频率对数坐标不显示 0 Hz（起始频率为零时，显示下限采用终止频率的千分之一）。已有会话中明确保存的坐标选项会继续恢复。

- FFT 幅度谱适合观察确定性周期分量。
- Welch 功率谱密度通过分段平均降低方差，更适合噪声背景下比较频率分布。
- 选区越长，频率分辨率通常越高，但局部瞬态会被时间平均。
- 50 Hz 及其倍频可能来自工频耦合，不应直接解释为分子特征。

## 空白参考

选择空白文件夹后，程序均匀抽取最多 10 个完整文件，计算中位频谱与四分位范围。空白和样品应尽量使用相同采样率、偏压、带宽和仪器条件。

## 筛选与导出

标记与备注会自动保存；“保存文件标记”可用于立即落盘。“保存当前区间”会保存时间范围、统计量、主要峰，以及全局、局部、频谱和组合图快照。

已保存区间表支持按行多选：按住 `Ctrl` 可逐条增减选择，按住 `Shift` 可连续选择。选择后可以批量删除筛选记录，或仅导出选中的信号；批量删除不会修改原始 TDMS 文件。“导出全部结果”仍会导出所有已保存区间。

结果导出可以按需包含：

- `summary/feature.csv`：区间、标签、备注、统计量和主要频率峰；
- `summary/I-T_raw_data.csv`：每个导出区间内逐采样点的时间和电流原始数据，并附源文件、通道、区间、备注和电流单位；
- `signals/`：每条筛选信号一个独立原始 I–T CSV 子表；
- `analysis_session.json`：用于追溯的会话信息；
- `report.html`：筛选结果摘要；
- `images/`：用户选择的全局图、局部图、频谱图和组合图。

不再生成 `file_marks.csv` 和 `candidate_regions.csv`。导出的图片按“源文件名_起点-终点s_备注_图像类型.png”命名；空备注显示为“无备注”，Windows 文件名中的非法字符会自动替换。

### 自定义导出内容

点击“导出选中信号”或“导出全部结果”后，程序会先显示导出内容选择窗口。可以分别选择：

- 全局图、局部图、频谱图和全局—局部组合图；
- `feature.csv` 特征汇总总表；
- `I-T_raw_data.csv` 原始 I–T 数据总表；
- 每条筛选信号的独立 CSV 子表；
- `analysis_session.json` 和 `report.html`。

“全选”和“取消全选”可以快速调整选项；至少需要选择一项。“记住本次导出选项”启用后，下次导出会沿用本次组合。

导出结果按内容组织：

```text
TDMS筛选结果_时间/
├─ summary/
│  ├─ feature.csv
│  └─ I-T_raw_data.csv
├─ signals/
│  └─ 每个保存区间一个独立 CSV
├─ images/
│  └─ 仅包含勾选的图片类型
├─ analysis_session.json
└─ report.html
```

未勾选的文件和目录不会生成。逐信号 CSV 使用与图片一致的“源文件名_起点-终点s_备注.csv”命名，表内保留源文件、通道、区间、备注、时间、电流和单位，因此可以脱离总表单独追溯。

## 处理会话与断点续处理

程序会按数据文件夹自动维护处理会话。文件标记、备注草稿、已保存区间、每个文件的局部窗口、最后处理文件、当前通道、时间单位、FFT 范围、频谱模式、窗函数、对数坐标和空白叠加状态都会自动保存。界面中的会话状态会显示已处理文件数量和最近保存时间。

- “保存进度”会立即保存当前状态；日常操作通常无需手动点击。
- “另存会话…”会生成可命名的 `.tdms-session.json` 文件，并在后续操作中同步自动保存。
- “打开会话…”可以打开命名会话或此前导出的 `analysis_session.json`。
- 如果会话中的原数据目录已经移动，程序会要求重新选择 TDMS 数据文件夹；文件记录使用相对名称重新绑定。
- 每次覆盖会话前都会保留同目录的 `.bak`。主会话损坏时，程序会自动尝试从备份恢复并显示提示。

同一数据文件夹的默认会话会在下次启动时自动恢复。需要保存“初筛”“复查”等多个独立进度时，请分别使用“另存会话…”。

## 组合图

“导出组合图”会生成一张上下布局的 PNG：上半部分是带局部选区的全局 I–T 图，下半部分是对应选区的局部放大图，顶部包含源文件、通道、区间和备注。保存新区间时也会记录组合图；导出当前图像、选中信号或全部结果时会一并输出可用的组合图。
