# 用户指南

## 选择数据

“数据文件夹”应直接包含 `.tdms` 文件。程序默认选择长度最长的数据通道；若文件包含多个通道，可在“数据通道”下拉框切换。

## 局部窗口与时间

拖动右上总览中的选择框即可改变局部窗口。也可精确输入起点、终点或窗口宽度，并在秒与毫秒之间切换。窗口到达数据边界时会自动限制，且至少保留 16 个采样点用于频谱计算。

## 频谱

- FFT 幅度谱适合观察确定性周期分量。
- Welch 功率谱密度通过分段平均降低方差，更适合噪声背景下比较频率分布。
- 选区越长，频率分辨率通常越高，但局部瞬态会被时间平均。
- 50 Hz 及其倍频可能来自工频耦合，不应直接解释为分子特征。

## 空白参考

选择空白文件夹后，程序均匀抽取最多 10 个完整文件，计算中位频谱与四分位范围。空白和样品应尽量使用相同采样率、偏压、带宽和仪器条件。

## 筛选与导出

文件标记与备注需要点击“保存文件标记”。“保存当前区间”会保存时间范围、统计量、主要峰和两张快照。完整导出包含文件标记 CSV、候选区间 CSV、会话 JSON、HTML 报告和可用快照。
