TDMS Viewer — Windows Portable
==========================================

1. Keep the extracted folder intact.
2. Double-click TDMS-Viewer.exe.
3. Screening records and settings are created in user_data beside the EXE.
4. The application never modifies source TDMS files.
5. This build is unsigned. Verify SHA256SUMS.txt after downloading.

The software supports preliminary signal screening and is not, by itself,
proof of molecular identity.
